# TimeSeal · Brand Guidelines

> Stamp URLs with the current time and always load the freshest page.

## Name

| Use | Value |
| --- | --- |
| Name | TimeSeal |
| Full title | TimeSeal — URL timestamp force refresh |
| npm package | `time-seal` |
| Repository | `webext-enforce-url-timestamp` |
| Slogan | Stamp URLs with the current time and always load the freshest page |

Naming logic: **Time** + **Seal**, matching the extension's core action — stamping a
`?t=<epoch ms>` onto matching URLs before navigation.

## Palette (Ocean Depths)

| Role | Name | Hex | Use |
| --- | --- | --- | --- |
| Background / text | Deep Navy | `#1A2332` | Promo backgrounds, dark body text |
| Primary | Teal | `#2D8B8B` | Buttons, switches, emphasis, links |
| Primary dark | Teal Deep | `#236F6F` | hover / pressed states |
| Primary light | Teal Bright | `#3AA6A6` | Icon gradient start, glow |
| Secondary | Seafoam | `#A8DADC` | Strokes, subtitles, accents |
| Light surface / clock face | Cream | `#F1FAEE` | Card surfaces, icon base |

Exposed in UnoCSS as `brand-*`: `brand-50/100/200/400/600/700/900` (see `unocss.config.ts`).

## Typeface

- UI: system sans-serif stack (`font-sans`), no web fonts loaded.
- Promo art / docs: `Inter` for Latin text; code and URLs use a monospace font.

## Icons

- `extension/assets/icon.svg` — full version: rounded badge + stamp perforation ring + clock.
- `extension/assets/icon-small.svg` — simplified: no perforation ring, bolder hands, for 16/32px.
- Exported PNGs: `icon-16/32/48/128/512.png`, generated from the SVGs with `rsvg-convert`.
- Minimum usable size is 16px; the same version is used on dark and light backgrounds, with no
  outline and no shadow (the container decides).

Regenerate the icon PNGs:

```bash
cd extension/assets
rsvg-convert -w 512 -h 512 icon.svg -o icon-512.png
rsvg-convert -w 128 -h 128 icon.svg -o icon-128.png
rsvg-convert -w 48  -h 48  icon.svg -o icon-48.png
rsvg-convert -w 32  -h 32  icon-small.svg -o icon-32.png
rsvg-convert -w 16  -h 16  icon-small.svg -o icon-16.png
```

the built extension to capture the real UI, then composes the promo images from HTML.

| File | Size | Use |

| `screenshot-3-shortcut.png` | 1280×800 | Shortcut toggle |

Build first: `mise run build && nub scripts/store-assets.ts`.
